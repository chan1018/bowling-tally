# 3ゲーム目のチームは 1G+2G の点数で組む（運営メモの記述に反する）

運営メモ §5 は「3ゲーム目は**2ゲーム目の順位だけ**で決める（1G+2Gの足し算は不要）」と明記しているが、
アプリでは **1ゲーム目＋2ゲーム目の点数**で組む。

## なぜ

運営メモがそう書いた理由もメモ自身に書かれている ——「1G+2Gの足し算は不要」、つまり**当日その場で手計算したくない**から。
アプリを使う時点でこの制約は消える。そして統計的には2ゲーム分のほうが実力推定として明確に安定する。
ボウリングは1ゲームのブレが大きく（同じ人でも±30点は普通）、2ゲーム目だけを見ると
「たまたま当たった人／たまたま外した人」を実力と誤認し、3ゲーム目のチーム平均差が逆に開く。

## 却下した案

**1G:2G に重み付けをする。** 1ゲーム目は練習なので初心者ほど実力より低く出る、という懸念は実在する。
しかし2ゲーム目にも同じ人の実力は現れており、重みの根拠になる実測データは無い。
根拠のないパラメータを増やすのは投機的な作り込みなので **1:1 のまま**とした。

## 将来の読者へ

運営メモとアプリの挙動が食い違って見えたら、それは**バグではなくこの決定**である。
紙で運営する場合（アプリが開かない等の事故時）は、運営メモ §5 の固定表をそのまま使ってよい。
順位ベースなので平均点は揃わないが、当日の手計算では実用上そこが限界になる。
